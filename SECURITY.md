# Security Policy

## Supported Versions

Only the latest release (specifically `v0.2.0-beta.0` or newer) is supported with security updates.

| Version | Supported |
| ------- | --------- |
| v0.2.0-beta.0 | :white_check_mark: |
| < v0.2.0-beta.0 | :x: |

## Reporting a Vulnerability

We take the security of EPIC seriously. If you find a security vulnerability or bug, please report it immediately by sending an email to **security@solana-epic.org** (or open an issue with appropriate security classifications).

Please include:
- A description of the issue or vulnerability.
- Steps to reproduce the issue.
- Potential impact and exploit vectors.
- Any suggested fixes or remediations.

We will acknowledge receipt of your report within 48 hours and work with you to coordinate a disclosure schedule.
